# 炸飞机 · 一图流玩法

> 在线玩：<https://thinktwice.top/bgx/> → 大厅选择「炸飞机」→ 创建房间 → 把链接发给朋友。

![炸飞机玩法一图流：目标、飞机形状、布阵、同轮报点、命中判定、胜负](plane-bomb-one-pager.png)

## 一句话规则

双方在 10×10 海域秘密摆 3 架飞机，每轮**同时**各报一个格子，两边都报完后**同时结算**；先击落对方 3 架者胜，同轮双方都到 3 架则平局。

## 最容易搞错的三件事

1. **只有机头被炸才算击落**。机身被炸只是命中，飞机不会掉。
2. **双方都报完才结算**。没有先后手，不存在“我先报就我先赢”。
3. **飞机被击落后，炸到它的机身仍然算命中**。机身始终是有效目标。

## 其他默认规则

- 飞机可朝上 / 右 / 下 / 左四个方向，机头位置 + 朝向决定整架飞机。
- 三架飞机不能重叠，不能越界；可以贴边、可以相邻。
- 布阵阶段双方都提交后才开战，提交前可以反复修改。
- 每轮每人 1 炮，命中不连击；已经炸过的格子不能重复报。
- 观战者在终局前看不到任何一方的舰队。
